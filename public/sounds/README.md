# Ambient Sound Files

Place ambient sound files here for the Focus Mode feature.

## Required Files

- `rain.mp3` - Rain/thunder ambient sounds
- `wind.mp3` - Wind ambient sounds  
- `cafe.mp3` - Coffee shop ambient sounds
- `ocean.mp3` - Ocean waves ambient sounds
- `lofi.mp3` - Lo-fi music for focus

## Recommended Sources

- [Pixabay](https://pixabay.com/music/) - Free royalty-free audio
- [Freesound](https://freesound.org/) - Creative Commons audio
- [Mixkit](https://mixkit.co/free-sound-effects/) - Free sound effects

## File Requirements

- Format: MP3 (for broad browser compatibility)
- Duration: 2-5 minutes (will loop automatically)
- Size: Keep under 5MB per file for fast loading
- Quality: 128-192 kbps is sufficient for ambient sounds
